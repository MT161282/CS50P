# CS50P: Introduction to Programming with Python

This repository contains my verified solutions to all 10 weekly problem sets and the capstone final project for **Harvard University's CS50's Introduction to Programming with Python**.

---

##  Capstone Final Project

### **NucCalc: Nuclear Engineering Calculator**
* **Directory:** `/final_project`
* **Overview:** A specialized computational tool designed for nuclear physics and safety calculations, featuring core modules for radiation attenuation, half-life decay, and shielding thickness analysis.
* **Key Components:**
  * `project.py`: Core application logic and algorithmic implementation.
  * `test_project.py`: Comprehensive test suite developed using `pytest`.
  * `requirements.txt`: Package dependencies and environment specifications.

## Skills & Technologies Demonstrated

* **Core Programming:** Data structures, recursion, dynamic loops, and functional paradigms.
* **Software Engineering Practices:** Defensive programming, exception handling, and automated unit testing via `pytest`.
* **Data Processing & Automation:** Parsing structured tabular data (`csv`), string pattern compilation with `re`, and binary file transformations with `Pillow`.
* **Object-Oriented Design:** Class construction, inheritance, encapsulation, operator overloading, and `@property` decorators.
